# Schattenwurf (Phase 3b-2): Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Analytische Schatten innerhalb eines Planetensystems (Mond im Planetenschatten, Mondschatten auf dem Planeten, Planet auf Ringen, Ringe auf dem Planeten) mit exaktem Halbschatten, Blutmond-Färbung, Schalter „Schatten" und einer Kinoszene, die die nächste echte Mondfinsternis zeigt.

**Architecture:** `render/shadows.ts` liefert die reine Rechnung (Kreisüberlappung, Ringtreffer, Okkluderauswahl, echte Sonnenrichtung) und den GLSL-Baustein; `bodies.ts` hängt ihn per `onBeforeCompile` an das `MeshStandardMaterial`, `rings.ts` an sein ShaderMaterial. Sonnenrichtung und Sonnenwinkel kommen aus der echten Geometrie (`positionAt`), Okkluder und Fragmente aus der dargestellten — innerhalb eines Planetensystems sind beide exakt ähnlich (`scaledPositionAt`). `sim/finsternis.ts` sucht die nächste Mondfinsternis; die Szene `mondfinsternis` springt beim Start dorthin.

**Tech Stack:** TypeScript (strict), Vite, React 19, Zustand, Three.js 0.186, Vitest (`node` für sim, `jsdom` für ui), Python 3.12 mit Pillow/numpy für Messskripte.

**Spec:** `docs/superpowers/specs/2026-09-13-schatten-design.md`

    ```glsl
    float sonnenAnteil(float alpha, float beta, float gamma) {
      if (gamma >= alpha + beta) return 1.0;
      if (beta >= alpha && gamma <= beta - alpha) return 0.0;
      if (beta < alpha && gamma <= alpha - beta) return 1.0 - (beta * beta) / (alpha * alpha);
      float a2 = alpha * alpha; float b2 = beta * beta; float g2 = gamma * gamma;
      float x = (g2 + a2 - b2) / (2.0 * gamma);
      float y = (g2 + b2 - a2) / (2.0 * gamma);
      float linse = a2 * acos(clamp(x / alpha, -1.0, 1.0)) + b2 * acos(clamp(y / beta, -1.0, 1.0))
                  - gamma * sqrt(max(a2 - x * x, 0.0));
      return clamp(1.0 - linse / (PI * a2), 0.0, 1.0);
    }
    float kugelSchatten(vec3 p, vec4 okkluder, vec3 sonne, float alpha) {
      vec3 zu = okkluder.xyz - p;
      float d = length(zu);
      if (dot(zu, sonne) <= 0.0) return 1.0;
      float beta = asin(clamp(okkluder.w / d, 0.0, 1.0));
      float gamma = acos(clamp(dot(zu / d, sonne), -1.0, 1.0));
      return sonnenAnteil(alpha, beta, gamma);
    }
    ```
    `SCHATTEN_GLSL_KOERPER_PARS` (Uniforms `uSonnenRichtung`, `uSonnenWinkel`, `uOkkluder[4]`, `uOkkluderFarbe[4]`, `uOkkluderAnzahl` (int), `uRingEbeneA` (mitte.xyz, innen), `uRingEbeneB` (normale.xyz, aussen), `uRingAktiv`, `tRingSchatten`, `varying vec3 vSchattenPos`) plus die Funktionen; `SCHATTEN_GLSL_KOERPER_ANWENDUNG`:
    ```glsl
    vec3 schattenFaktor = vec3(1.0);
    vec3 fuellFarbe = vec3(1.0);
    for (int i = 0; i < 4; i++) {
      if (i >= uOkkluderAnzahl) break;
      float f = kugelSchatten(vSchattenPos, uOkkluder[i], uSonnenRichtung, uSonnenWinkel);
      schattenFaktor *= f;
      fuellFarbe *= mix(vec3(1.0), uOkkluderFarbe[i], 1.0 - f);
    }
    if (uRingAktiv > 0.5) {
      float nenner = dot(uSonnenRichtung, uRingEbeneB.xyz);
      if (abs(nenner) > 1e-6) {
        float t = dot(uRingEbeneA.xyz - vSchattenPos, uRingEbeneB.xyz) / nenner;
        if (t > 0.0) {
          float r = length(vSchattenPos + t * uSonnenRichtung - uRingEbeneA.xyz);
          float u = (r - uRingEbeneA.w) / (uRingEbeneB.w - uRingEbeneA.w);
          if (u >= 0.0 && u <= 1.0) schattenFaktor *= 1.0 - texture2D(tRingSchatten, vec2(u, 0.5)).a;
        }
      }
    }
    reflectedLight.directDiffuse *= schattenFaktor;
    reflectedLight.directSpecular *= schattenFaktor;
    totalEmissiveRadiance *= fuellFarbe;
    ```
    `SCHATTEN_GLSL_VERTEX_PARS` = `varying vec3 vSchattenPos;`, `SCHATTEN_GLSL_VERTEX` = `vSchattenPos = (modelMatrix * vec4(transformed, 1.0)).xyz;`.
