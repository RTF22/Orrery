Rings" (arXiv 1112.3305). Für alle 22 neuen Katalogeinträge wurden Titel, Erstautor, Jahr, Zeitschrift,
Band und Seite über Crossref geprüft (`npm run literatur:pruefen`, Ergebnis unten); bei einem
